# Button tap sound

`soft-pop.wav` is an original, procedurally generated sound for MealPulse:
95 ms, mono, 44.1 kHz, PCM 16-bit, with a gently falling pitch and short decay.
It uses no third-party audio samples.

The app plays it at 35% volume through a shared preloaded player. Users can mute
button sounds in Menu PRO. App code and this asset follow the repository license.
